Date: 2026-05-25
Framework: v5.4.0
Tooling: `playwright==1.x` + `playwright_stealth==2.x` (chromium-1217 / Google
Chrome for Testing, arm64). Same combination that broke Smith TX
publicsearch.us in the prior session.

> County-side artifact. Generated by
> `runs/greene_ny/recon/stealth_probe/probe_sources.py` →
> `probe_turnstile.py` → `probe_courts_open.py` → `probe_wcs_submit.py` →
> `probe_wcs_warmed.py`. Raw HTML/PNG snapshots + JSON in the same dir.

## Goal

Determine whether stealth Playwright can break through the Cloudflare
Turnstile / Managed Challenge that was previously blocking Phase 3 on the
four session-required PRIMARY sources:

  1. `clerk_land_records` (SearchIQS — `searchiqs.com/nygre/`)
  2. `supreme_court_foreclosure` (NYSCEF — `iapps.courts.state.ny.us/nyscef/`)
  3. `surrogate_court_probate` (NYSCEF Surrogate; also WebSurrogate)
  4. `webcivil_supreme` (`iapps.courts.state.ny.us/webcivil/FCASSearch`)

Plus the unconfirmed `legal_notices_column` (Next.js SPA) — left aside for
this pass; existing adapter is in place.

## Headline

**Stealth Playwright clears the first navigation for SearchIQS, NYSCEF
Case-Search, WebCivil Supreme Search forms, and WebSurrogate Welcome — the
landing HTML renders fully and the forms are characterized cleanly. But
EVERY *actionable* request behind these surfaces (guest-login click, search
submit, sub-page navigation) triggers a Cloudflare Managed Challenge
(`cType: 'managed'`, `_cf_chl_opt` interstitial, `cf-turnstile-response`
input) that DID NOT auto-resolve under stealth.** Verified across cold
contexts, warmed contexts (multi-step prior browsing in the same session),
slow human-paced typing/clicking, 60-second auto-resolve polling, and
attempts to click the challenge iframe (no iframe is reachable — Cloudflare
serves the interstitial as a top-level page, not a widget).

**Verdict: SearchIQS + NYSCEF Supreme + NYSCEF Surrogate + WebSurrogate +
WebCivil Supreme remain SOURCE_FOUND_CAPTCHA. Stealth alone is insufficient.
Operator input is required.** Same conclusion as the 2026-05-21 re-recon,
now with stealth empirically ruled out as well.

The earlier `tax_foreclosure_auction`, `tax_foreclosure_petition`, and
`legal_notices_column` PRIMARY sources are unaffected and remain LIVE.

## Per-source observed behavior

### 1. SearchIQS — `searchiqs.com/nygre/`

| Step | Method | Outcome |
|---|---|---|
| Cold GET landing | Stealth chromium | HTTP 200; title `Greene County, NY - SearchIQS`; ASP.NET login form fully present (12 inputs: VIEWSTATE/EVENTVALIDATION + `username`/`password`/`btnGuestLogin`). **PASS.** |
| Click `#btnGuestLogin` | Stealth chromium | Same tab transitions to `cType: 'managed'` Cloudflare Managed Challenge (`Just a moment…`). `cf-turnstile-response` hidden input present. No widget iframe is served — the interstitial is the full page. 40 s poll: **NOT RESOLVED.** |

Why this is hard: the Turnstile token is required to obtain the guest
session cookie that the rest of `/nygre/` (`Search.aspx`, `Index.aspx`,
`DocumentList.aspx`) reads. Until that token is minted, no further
endpoints are reachable.

**Operator unlock (any one of):**
- Provide a `cf_clearance` cookie value AND the IQS ASP.NET session cookie
  pair (`ASP.NET_SessionId`, `IQSCustomerID`/`IQSAuthToken`) captured from
  a real desktop browser session that just passed the guest-login challenge.
  These can be pasted into `runs/greene_ny/recon/operator_verified_sources.yml`
  under a new `searchiqs_session` key — the framework will read them and
  inject into the adapter's HTTP client.
- OR run the adapter inside a headful Playwright container with a
  pre-warmed user profile directory whose Cloudflare challenge has been
  human-solved once (challenge cookie survives ~24 h).
- OR procure a paid SearchIQS subscription account; subscriber sessions
  are not Turnstile-gated.

OR an authenticated NYSCEF account (subscriber cookies bypass the

## What stealth DID prove

Stealth Playwright successfully reaches the search/landing surfaces of
every gated source — meaning the source-of-record matrix's
"SOURCE_FOUND_CAPTCHA" classification is correct and the surfaces are
**live and documented**, not dead. The forms are now characterized in
machine-readable detail (parameter names, court codes, case-type codes,
form-post URLs) — enough that the adapters can be written in 30 minutes
once Cloudflare lets actionable requests through:

- `runs/greene_ny/recon/stealth_probe/courts_open.json` — full WebCivil
  Supreme + WebSurrogate form spec + 119-court list with Greene codes.
- `runs/greene_ny/recon/stealth_probe/probe_deep.json` — NYSCEF case-type
  enum (~200 case types with encoded values) + Greene county value=`20`.
- `runs/greene_ny/recon/stealth_probe/probe_results.json` — SearchIQS
  guest-login button + form-post-back shape (ASP.NET viewstate).

## What stealth did NOT prove and CAN'T

Cloudflare Managed Challenge ≠ the no-interaction Turnstile variant that
playwright-stealth bypasses on publicsearch.us. Managed Challenge expects
the browser to execute a JS verification routine and POST a server-side
verification request back to Cloudflare; the verification call's body is
fingerprint-derived (canvas hashes, headless-detection probes), and
Cloudflare flagged the request HARD enough that the verification call
returned a challenge-not-resolved response on every attempt. No widget
iframe is even served — meaning there's no checkbox to click as a fallback.

## Bottom line

The original 2026-05-21 §16 verdict stands: **session-required, not dead.**
Stealth Playwright did not promote any of these four sources from
SOURCE_FOUND_CAPTCHA to LIVE. The build remains in `SOURCE_LIMITED` mode
with the three already-live primaries (AAR tax-foreclosure auction,
Treasurer petition PDF, Column legal notices) carrying the lead total.

A single operator-supplied `cf_clearance` cookie pair (plus session
cookies where applicable) unlocks SearchIQS, NYSCEF (Supreme +
Surrogate via Case Search), WebSurrogate, and WebCivil Supreme. The
recon evidence is now machine-readable enough that the adapters can be
shipped immediately upon cookie injection.
